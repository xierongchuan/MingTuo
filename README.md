# СтройМаркет — сайт-визитка

## Быстрый запуск

```bash
podman compose up -d --build
```

Сайт будет доступен по адресу: http://localhost:8080

## Как редактировать

- **Товары**: редактируйте файл `data/products.yaml`
- **Текст на главной**: редактируйте `content/_index.md`
- **Контакты, название, телефон**: редактируйте `hugo.toml` (секция `[params]`)
- **Картинки товаров**: положите файл в `static/images/` и укажите имя в `products.yaml`

После изменений пересоберите:

```bash
podman compose up -d --build
```
